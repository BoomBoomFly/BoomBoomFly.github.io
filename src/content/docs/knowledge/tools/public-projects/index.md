### 实验室仓库

- [BoomBoomFly](https://github.com/BoomBoomFly/BoomBoomFly) 收录室内无人机科研工作区的说明、工程脚本与版本清单。
- [XTARK](https://github.com/BoomBoomFly/xtark) 收录 ROS 1 移动机器人与机械臂的工程资料，包括底盘、传感器和功能包说明。
- [实验室网站源码](https://github.com/BoomBoomFly/BoomBoomFly.github.io) 使用 Astro 构建网站，用 Starlight 发布工程知识库。网站仓库的 README 说明了本地预览和发布方法。

### 上游项目的派生仓库

- [OpenVINS](https://github.com/BoomBoomFly/open_vins) 使用相机与惯性测量数据估计运动状态。上游为 [rpng/open_vins](https://github.com/rpng/open_vins)。
- [serial_driver_ros](https://github.com/BoomBoomFly/serial_driver_ros) 用于机器人上位机和下位机之间的串口通信，文档说明了收发数据的帧格式。上游为 [CGC12123/serial_driver_ros](https://github.com/CGC12123/serial_driver_ros)。
