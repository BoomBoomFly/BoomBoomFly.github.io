### 推荐阅读路径

1. [嵌入式：51 单片机与 STM32 零基础学习路线](/knowledge/tools/learning-paths/embedded/)
2. [Git：Git 零基础学习路线](/knowledge/tools/learning-paths/git/)
3. [C++：C++ 机器人开发学习路线](/knowledge/tools/learning-paths/cpp/)
4. [Linux：Linux 工程实践学习路线](/knowledge/tools/learning-paths/linux/)
5. [ROS 2：ROS 2 机器人开发学习路线](/knowledge/tools/learning-paths/ros2/)
6. [PX4：PX4 无人机学习路线](/knowledge/tools/learning-paths/px4/)

```text
嵌入式（51 单片机 → STM32） → Git → C++ → Linux → ROS 2 → PX4
```

这条路径表达的是常见的能力衔接：先通过嵌入式实验建立“代码—硬件—调试”的直觉，再用 Git 管理已有工程；随后补齐 C++ 和 Linux 工程能力，最后进入 ROS 2 与 PX4 系统开发。已有相应基础时可以跳转、并行学习或从中间开始，以目标路线列出的前置能力和验收项作为判断依据。

### 选读路线

- [FPGA：FPGA 零基础学习路线](/knowledge/tools/learning-paths/fpga/)

FPGA 是独立选读内容，不是进入 ROS 2 或 PX4 的前置条件。可以随项目需要开始；进入 FPGA 工程管理前建议掌握 Git，进入 HLS 阶段前应具备相应的 C/C++ 基础。
