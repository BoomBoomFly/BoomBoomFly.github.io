自主空中机器人依托机载传感、机载计算与控制完成闭环飞行任务，而非依赖多名地面操控员进行远程驾驶。

### 1. 空中平台选型与自主导航闭环

#### 1.1 常见构型对比

| 构型 | 核心优势 | 主要局限 |
| --- | --- | --- |
| **固定翼** | 续航长、负载能力强 | 通常需要跑道、存在失速风险、气动设计复杂 |
| **直升机** | 可垂直起降、负载与续航居中 | 机械结构与旋翼控制复杂 |
| **多旋翼** | 结构简单、垂直起降、机动性好，适合小型自主系统 | 续航较短、负载有限、本体不自稳（高度依赖 MEMS IMU 与飞控闭环） |
| **混合翼 / 扑翼** | 试图兼顾垂直起降、长续航或微型化 | 系统气动与控制复杂度更高 |

#### 1.2 自主导航 7 步闭环

```text
传感采集 → 定位 / 状态估计 → 建图 → 路径搜索 → 轨迹生成 → 控制执行 → 在线重规划
```

1. **传感**：相机、IMU、激光雷达、GPS 等提供原始观测；
2. **定位 / 状态估计**：输出低延迟、高精度、时间一致的位姿与速度；
3. **建图**：将环境表示为点云、占据栅格、OctoMap 或 ESDF，供碰撞检测与规划查询；
4. **路径搜索**：在自由构型空间中找到起点到终点的无碰撞几何路径；
5. **轨迹生成**：将几何路径转化为时间参数化、光滑且动力学可行的参考轨迹；
6. **控制**：依据期望轨迹与状态估计计算总推力、力矩并分配至各电机；
7. **在线重规划**：随新观测、外力扰动或目标变更滚动更新。

> 自主无人机落地的三大核心挑战可归纳为：**轻量化、鲁棒性、高机动性**。

### 2. 硬件组件选型与动力估算

#### 2.1 八大核心组件选型指标

| 组件 | 核心职责 | 主要选型指标 |
| --- | --- | --- |
| **飞控** | 读取传感器与上层/遥控指令，输出电机或舵机控制 | IMU 冗余、气压计/磁罗盘、UART/I2C/CAN/GPS 接口、减振温控与生态 |
| **ESC 电调** | 将飞控命令转换为无刷电机三相驱动 | 单体/四合一、额定与峰值电流、通信协议（如 DShot/PWM）、散热 |
| **无刷电机与桨** | 产生升力与三轴控制力矩 | 尺寸、适配桨径、KV 值、推力曲线、力效、重量 |
| **锂电池** | 为动力、飞控与机载计算平台供电 | 串数/电压（S）、容量（mAh）、放电倍率（C）、重量 |
| **机架** | 承载整体结构并固定相对几何布局 | 轴距、重量、结构刚度、可扩展性与抗振特性 |
| **机载电脑** | 运行 VIO/SLAM、建图、规划与视觉识别 | CPU/GPU 算力、架构（ARM/x86）、内存/存储、接口、功耗与重量 |
| **感知传感器** | 提供定位、深度与语义观测 | 量程、视场角（FOV）、帧率、延迟、精度、重量与环境适应性 |
| **接收机 / GPS / 电压计** | 人工安全接管、室外定位与电源监控 | 通道数、链路可靠性、定位精度、低压报警阈值 |

#### 2.2 动力与续航粗估公式

- **空载转速估算**：$\mathrm{RPM} \approx KV \times V$。高 KV 常匹配小桨与高转速，低 KV 常匹配大桨与较高电压；选型时必须将电压、桨叶尺寸与电流余量联合评估。
- **推力与反扭矩**：$F_i = k_F \omega_i^2$，$M_i = k_M \omega_i^2$。
- **悬停功率与续航粗估**：若平台总重为 $W_g$（g），当前桨-电机组合在悬停点附近的力效为 $\eta$（g/W），电池电压为 $V$，则：
  $$
  P_h = \frac{W_g}{\eta}, \qquad I_h = \frac{P_h}{V}, \qquad C \approx I_h \cdot t
  $$
  其中 $t$ 为悬停时间（小时）。工程核算时须叠加电池可用容量上限、电芯老化、低温衰减、机动峰值电流与安全余量。

#### 2.3 任务驱动的 7 步设计流程

**核心原则：先由任务推导需求，再选硬件**；切忌由手头现成计算板或电机反向拼凑任务。

1. 明确任务指标（环境、飞行速度、负载、续航、定位条件、识别需求）；
2. 按环境选择传感器（外部动捕/GPS、双目红外/RGB-D、激光雷达、独立视觉相机）；
3. 按负载与传感视场选择机架（预留传感器视场、质心重合与维护空间）；
4. 按总重与机动推重比选定电机、桨叶、电调与电池；
5. 按算法负载选定机载电脑（VIO/规划侧重 CPU 单核与内存带宽，深度学习识别需要 GPU）；
6. 完成三维建模、结构件设计、电磁隔离与线束布置；
7. 分级推进验证：**单组件 → 动力台架 → 飞控自稳 → 状态估计 → 规划控制 → 全任务联调**。

### 3. 跨模块接口契约与常见系统误区

#### 3.1 模块间最低接口契约

| 上游 → 下游 | 至少需要传递的信息 |
| --- | --- |
| **传感器 → 状态估计** | 带精确采样时间戳的原始数据、标定参数、明确坐标系 |
| **状态估计 → 建图 / 规划 / 控制** | 位姿、线速度、角速度、协方差/健康状态、时间戳 |
| **建图 → 规划** | 占据/空闲/未知状态，或障碍距离与梯度、地图坐标系与分辨率 |
| **路径搜索 → 轨迹生成** | 有序航点、安全通行走廊、障碍距离、起终边界状态 |
| **轨迹生成 → 控制** | 位置、速度、加速度、偏航（高阶控制还需 jerk / snap） |
| **控制 → 执行器** | 总推力与力矩（或电机命令）、饱和与失效状态 |

#### 3.2 常见系统级误区

- 把“无碰几何路径”当作“可执行轨迹”，忽略转角突变与极短线段引发的饱和与振荡；
- 只看规划成功而忽略状态估计延迟，使规划器基于滞后世界状态做决策；
- 只调 PID 参数，不核对质量、惯量、推力模型、坐标系符号与电机饱和余量；
- 把点云、占据栅格与 ESDF 当作等价地图，忽视查询接口与增量维护成本差异；
- 仅在离散时间采样点校验碰撞或动力学约束，漏掉采样间隔内的穿障；
- 直接用绝对时间和未平移的大尺度坐标求解高次多项式，引发数值病态；
- 忽略未知空间的策略定义，以及将特定硬件平台基准当作通用性能保证。

### 4. 代表性自主系统谱系

- **Teach-Repeat-Replan**：示教路径 + 全局建图与飞行空间生成 + 全局时空优化 + 在线局部重规划（“离线全局 + 在线局部”分层架构）。
- **EGO-Planner / EGO-Swarm**：基于均匀 B 样条与碰撞排斥梯度，不依赖全局 ESDF 的高速在线局部重规划与去中心化集群系统。
- **GCOPTER**：基于安全飞行走廊与 MINCO 轨迹表示的连续时间轨迹优化组件。
- **Aerostack2**：提供平台适配、Motion Reference、Controller、Behavior Action 与 Behavior Tree 编排的 ROS 2 无人机自治框架。
