前端路径搜索只回答“从哪里走”的几何问题；后端轨迹优化负责赋予时间参数、速度、加速度与高阶连续性，向控制器输出动力学可行的参考轨迹 $(p_{\text{ref}}, v_{\text{ref}}, a_{\text{ref}}, \psi_{\text{ref}})$。

### 1. 构形空间与前端图搜索

#### 1.1 构形空间（C-Space）

构形空间 $C = C_{\text{obs}} \cup C_{\text{free}}$ 包含机器人所有自由度的取值集合。工程上常将有体积机器人保守近似为圆或球体，并把工作空间障碍物按该半径向外膨胀为 $C_{\text{obs}}$，从而把复杂的包络碰撞检测化简为 $C_{\text{free}}$ 内的点碰撞查询。

#### 1.2 图搜索统一框架

搜索循环按特定规则从待访问容器中弹出节点 $\to$ 扩展邻居 $\to$ 更新代价与父指针 $\to$ 入队：

| 算法 | 弹出规则 / 特点 | 典型场景 |
| --- | --- | --- |
| **DFS / BFS** | 栈（LIFO）或队列（FIFO）；BFS 在无权图最优但扩展范围大 | 拓扑连通性、小图基础遍历 |
| **Greedy Best-First** | 最小 $h(n)$；目标导向强但复杂障碍下可能走远 | 简单开阔地快速试探 |
| **Dijkstra** | 最小 $g(n)$；非负边权下严格最优 | 离线距离场、多终点代价表 |
| **A\*** | 最小 $f(n)=g(n)+h(n)$；可采纳启发式 $h(n)\le h^*(n)$ 下严格最优 | 2D/3D 栅格全局规划 |
| **Weighted A\*** | $g(n)+\varepsilon h(n)\;(\varepsilon>1)$；以有界次优性换取更高实时性 | 实时在线前端搜索 |
| **JPS** | 在均匀栅格上沿直线/对角跳跃，仅在强迫邻居处扩展，比 A\* 快数倍 | 无人机高速 3D 前端搜索 |
| **Hybrid A\*** | 在 $(x,y,\theta)$ 空间按车辆运动基元扩展并结合 Reeds-Shepp 解析加速 | 阿克曼小车、自动泊车 |

- **8 邻域二维栅格对角线启发式**：
  $$
  h = (d_x + d_y) + (\sqrt{2} - 2)\min(d_x, d_y)
  $$
- **平局打破（Tie-Breaking）**：对 $f(n)$ 相等的节点施加极小启发式微扰或叉积偏置，引导路径走直线、减少对称冗余扩展。

### 2. 高维采样规划（PRM / RRT / RRT\*）

在 6/7 轴机械臂或高维状态空间中，规则网格面临维数灾难，应采用随机采样规划：

- **PRM（多查询）**：离线在自由空间撒点并连接 $k$ 近邻构建路标图，在线直接用 Dijkstra/A\* 查询，适合静态工作站重复作业。
- **RRT / RRT-Connect（单查询）**：利用 Voronoi 偏置快速探索未知空间；双向生长的 RRT-Connect 求解速度显著快于单向 RRT。
- **RRT\* 与 Informed RRT\***：通过“邻域重选父节点 + 重布线（Rewire）”实现渐近最优；得到可行解后，Informed RRT\* 只在以起终点为焦点的超椭球内采样以加速收敛。
- **工程要点**：采样规划 90% 以上耗时在碰撞检测（常用 FCL + BVH 或 ESDF）；原始锯齿路径需先做 Shortcut 剪枝再进入平滑优化。

### 3. 后端轨迹优化与连续约束

#### 3.1 五次多项式与 Minimum-Snap 闭式求解

- **五次多项式边界平滑**：一维五次多项式含 6 个系数，可由段首/段末的位置、速度与加速度 6 个边界条件唯一确定；多段轨迹需在航点处保持位置、速度与加速度连续，三轴共享分段时间。
- **Minimum-Snap 优化**：以位置四阶导数（Snap）平方积分为代价，每段常用 7 次多项式（$2\times 4 - 1 = 7$）：
  $$
  \min_c \int_0^T \left\|\frac{d^4 p(t)}{dt^4}\right\|^2 dt = c^T Q c \quad \text{s.t.} \quad A c = b
  $$
  工程上常通过映射 $M p = d$ 将多项式系数转为端点导数并分离“固定导数”与“自由导数”，把等式约束二次规划转为数值更稳健的无约束二次型闭式求解；若叠加凸多面体安全飞行走廊（SFC），则转为稀疏 QP。

#### 3.2 B 样条与无 ESDF 局部重规划（EGO-Planner）

传统梯度避障需消耗大量算力维护三维欧氏距离场（ESDF）。EGO-Planner 利用均匀 B 样条的凸包性与局部修改性，仅在轨迹穿入障碍时沿无碰撞引导路径构造排斥梯度，联合平滑代价、碰撞代价与动力学可行性代价做快速无约束优化，将局部重规划压缩到毫秒级。

#### 3.3 分层规划、数值稳定、时间分配与安全约束

1. **分层规划迭代**：前端生成无碰航点 $\to$ 后端生成光滑轨迹 $\to$ 碰撞检查；若轨迹切角进入障碍，在碰撞段增补航点或走廊约束后重算。
2. **数值稳定性**：每段采用归一化相对时间，避免小时间间隔导致高次幂矩阵病态；大尺度坐标应先平移缩放求解再映射回原坐标。
3. **时间分配**：先按平均速度或梯形曲线初估分段时间并在约束超限时放大，或将时间正则项直接纳入联合优化迭代求解。
4. **连续时间区间约束处理**：仅在离散采样点查碰撞会漏碰，工程上通过① 迭代检出违反点增补约束、② 凸包等保守包络约束，或③ 软约束优化后做严格连续碰撞与动力学复核来保障安全。

### 4. 地面移动机器人局部规划器（ROS 2 Nav2）

| 算法 | 核心原理 | 适用特点 |
| --- | --- | --- |
| **DWA / Regulated Pure Pursuit** | 速度空间短时采样评分 | 轻量稳健，但前瞻短、狭窄门口或 U 型障易受阻 |
| **TEB** | 图优化时间弹性带 | 支持阿克曼与自动倒车脱困，偶发局部极小 |
| **MPPI** | 信息论随机采样加权控制 | 原生支持非凸障碍与非线性动力学，算力要求较高 |

> **安全底线**：未知空间不等于自由空间；局部规划器不能替代底层近距硬急停与超时停车保护。
