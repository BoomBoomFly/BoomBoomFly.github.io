机器人系统常跨越 MCU、FPGA、机载 Linux 计算单元与地面站多级链路。保证通信可靠的本质不是“能收到字节”，而是明确**物理时序、帧边界、版本契约与端到端执行语义**。

### 1. 串行通信协议对比与关键时序（UART / SPI / I²C）

| 协议 | 双工与同步 | 信号线 | 寻址方式 | 典型场景 |
| --- | --- | --- | --- | --- |
| **UART** | 全双工、异步 | `TX`、`RX`、`GND` | 点对点 | 调试串口、GPS、激光雷达、无线模块 |
| **SPI** | 全双工、同步 | `MOSI`、`MISO`、`SCLK`、`CS` | 独立片选 `CS` | 高速 Flash、显示屏、IMU / ADC（常 $\ge 10\text{ Mbps}$） |
| **I²C** | 半双工、同步 | `SDA`、`SCL`（开漏+上拉） | 7/10-bit 唯一地址 | 多路低速传感器、EEPROM、RTC |

- **UART**：空闲高电平，起始位 `0` + 5～8 位数据（LSB 在前）+ 可选奇偶位 + 1～2 位停止位 `1`，双方靠波特率对齐采样节拍。
- **SPI**：唯一主机产生时钟，收发本质是移位寄存器同步交换——没有纯粹“只读”操作，读取从机数据时主机必须发送哑字节（Dummy Byte）提供时钟；须核对 CPOL/CPHA 四种模式。
- **I²C**：`SCL = 1` 期间 `SDA` 必须保持稳定（高电平期间 `SDA` 下降为 START、上升为 STOP）；每传送 8 bit 后的第 9 个时钟由从机回传低电平 ACK 或高电平 NACK。
- **OSI 分层与 FPGA 以太网边界**：MAC/ARP 属数据链路层，IP/ICMP 属网络层，UDP 属传输层；FPGA 裸机以太网 UDP 模块通常做到传输层，物理层由外部 PHY 芯片承担。

### 2. STM32 HAL 串口状态机解包与 Linux Socket

#### 2.1 STM32 单字节中断状态机模式

在飞控串口通信、蓝牙或串口屏场景中，推荐**单字节中断接收 + 状态机帧解析 + 标志位主循环解耦**：

1. 在 `HAL_UART_RxCpltCallback()` 中按串口实例分流，立即重挂下一字节 `HAL_UART_Receive_IT(..., 1)`；
2. 状态机依次完成：双字节帧头匹配 $\to$ 记录有效长度 `data_len` $\to$ 按长度接收负载并累加校验和 $\to$ 核对校验和/帧尾；通过则拷贝至完整包缓存并置位接收标志；
3. 主循环轮询标志位并清除后完成字节序拼接与物理量缩放，避免在中断内执行耗时业务。

#### 2.2 Linux TCP Socket C/S 核心调用流

- **服务端**：`socket(AF_INET, SOCK_STREAM, 0)` $\to$ `bind()` $\to$ `listen()` $\to$ `accept()` $\to$ 循环 `recv()` / `send()` $\to$ `close()`；
- **客户端**：`socket()` $\to$ `inet_pton()` / `htons()` $\to$ `connect()` $\to$ 循环 `send()` / `recv()` $\to$ `close()`；
- 二进制流协议在 TCP 上无天然包边界，必须编写**流式环形缓冲解帧器**，覆写粘包、半包与错误头丢弃恢复的单元测试。

### 3. 多跳 UDP 任务事务与遥测版本契约

在“前端 / 上位机 $\to$ 机载网桥 $\to$ UDP 分片 $\to$ 下位机固件”多跳链路中，严禁把单一 `success` 当作整条链路成功，必须区分四层结果：

1. **本地请求入队**：仅说明上层接口接收了请求；
2. **匹配分片 ACK**：仅说明下位机收到该片 UDP 帧（不等于任务完成）；
3. **遥测任务终态**（如 `reached` / `cancelled`）：固件上报任务终态，仍需核对 `boot_id`、`session_token` 与 `task_id`；
4. **物理运动与停车实测**：结合外部测量验证机械执行是否达标。

#### 关键工程规范

- **事务水位与身份绑定**：任务须绑定启动编号与会话令牌，防止重启或定位重置后重放旧目标；分片事务中途禁止穿插其他控制帧；区分“最高已受理事务水位”与“当前活动任务编号”。
- **协议版本号透传**：同一字节偏移在不同协议版本（如不同遥测布局）中含义可能完全不同，版本号必须沿网桥、ROS 与 UI 全链路透传，严禁旧标签误读新字段。
- **控制权与授权分离**：区分“软件速度授权”与“底层电机硬件门控”，普通只读监看不得取消已有局部任务，显式停止、急停与人工接管必须立即撤销原任务。

### 4. ESP8266 无线串口联网与 AT 指令要点

- 调试前先发 `AT+GMR` 确认 ESP-AT 固件版本，不同版本指令存在差异；MCU 控制推荐发 `ATE0` 关闭回显。
- **工作模式**：`AT+CWMODE=1` 为 STA（连外部路由器/热点），`2` 为 AP（设备开热点直连调试），`3` 为 STA+AP。
- **单连接透传**：设置 `AT+CIPMUX=0` 与 `AT+CIPMODE=1`，建立 TCP/UDP 连接后执行 `AT+CIPSEND` 进入透传；退出透传需发送不带 `\r\n` 的 `+++`。
- **安全规范**：严禁将真实 Wi-Fi SSID 与密码写入代码仓库或公开笔记。
